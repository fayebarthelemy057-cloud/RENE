Digital Academy à télécharger

Récupérer le site Digital Academy sur ton ordinateur

Le bouton ci-dessous copie tout le site. Tu le colles dans le Bloc-notes et tu l’enregistres : tu obtiens le fichier digital-academy.html, qui s’ouvre dans ton navigateur.

  1. Clique sur Copier tout le site (au-dessus).
  2. Ouvre le Bloc-notes : touche ⊞ Win, tape « bloc-notes », puis Entrée.
  3. Colle avec Ctrl + V.
  4. Menu Fichier → Enregistrer sous. Choisis le Bureau.
  5. Nom du fichier : digital-academy.html. Type : Tous les fichiers (*.*). Encodage : UTF-8. Puis Enregistrer.
  6. Double-clique sur digital-academy.html sur ton Bureau : le site s’ouvre.

Si le bouton ne marche pas : clique dans le cadre ci-dessous, fais Ctrl + A (tout sélectionner) puis Ctrl + C (copier), et reprends à l’étape 2.
